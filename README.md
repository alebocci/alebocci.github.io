# Sito personale di Alessandro Bocci

Sito statico pronto per GitHub Pages. I file da pubblicare sono tutti contenuti in questa cartella.

## Pubblicazione

1. Crea un repository GitHub.
2. Carica il contenuto della cartella nella radice del repository.
3. In **Settings → Pages**, seleziona **Deploy from a branch**, branch `main`, cartella `/ (root)`.

## Pubblicazioni

Le pubblicazioni sono contenute in `publications.json`. L’editor grafico è distribuito separatamente e non va caricato nel repository pubblico.
